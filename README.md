# 🏪 Utz Najil POS — Sistema de Punto de Venta

Sistema completo para la gestión de restaurantes: ventas, pedidos, cocina, bar, reportes y control de licencias.

## ✅ Características principales

- 🛒 **Ventas rápidas** — Interfaz diseñada para agilizar el cobro
- 👨‍🍳 **Pantalla de Cocina** — Pedidos en tiempo real, control de estados
- 🍸 **Pantalla de Bar** — Comunicación inmediata con el área de preparación
- 📱 **Pedidos desde celular** — Los meseros envían comandas desde cualquier dispositivo
- 👥 **Gestión de usuarios** — Roles: administrador, cajero, mesero, cocina, bar
- 💾 **Respaldos completos** — Base de datos + imágenes en un solo archivo
- 🔒 **Protección de licencia** — Funciona solo en el equipo autorizado
- 📊 **Reportes** — Ventas, productos, caja y más

## 🚀 Instalación rápida

1. Descarga el archivo `.zip` desde **[Releases](https://github.com/Utznajil/UtzNajil-Descargas/releases/download/v1.0.0/UtzNajil_v1.0.rar)**
2. Descomprime en tu carpeta de proyectos
3. Abre en el navegador → se inicia el instalador automáticamente
4. Sigue los pasos y listo ✅
